Restaurant Rating Analysis Using Power BI

Project Overview

This project analyzes restaurant data using Microsoft Power BI to explore restaurant ratings, cuisines, and other key attributes. The goal is to transform raw data into meaningful insights through data preparation and interactive visualizations.

Project Objectives

- Analyze restaurant ratings.
- Explore restaurant cuisines.
- Build an interactive Power BI dashboard.

Dataset Description

The dataset contains restaurant-related information, including restaurant IDs, restaurant names, cuisines, ratings etc.

The original dataset is included in this repository for reference.

Tools and Technologies

- Microsoft Excel
- Microsoft Power BI
- Power Query, if used

Data Cleaning and Preparation

The data was reviewed and prepared for analysis by checking missing values, examining duplicates, validating data types as applicable. Restaurant IDs were retained where necessary to preserve relationships between restaurant and cuisine records.

Dashboard Features

This project may include KPI cards, tables, interactive filters, drill-through pages, and bookmarks, depending on the features implemented in the final report.



Repository Contents

How to Use This Project

1. Download the Power BI report and dataset.
2. Open the ".pbix" file in Microsoft Power BI Desktop.
3. Explore the dashboard and its available interactions.
